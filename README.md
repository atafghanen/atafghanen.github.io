# AT Evening Elegance – Version 7

## Enthalten
- Responsive Schwarz-Gold-Fashion-Website
- Rundes AT-Logo aus der bereitgestellten Datei
- Dezente 360°-Drehung des Logos ohne sichtbaren „360°“-Text
- Desktop, Laptop, Tablet und Smartphone Layout
- 4 Sprachen: Deutsch, Englisch, Pashto, Dari
- RTL-Unterstützung für Pashto und Dari
- Produktkatalog, Kategorien, Produktdetail-Modal und Warenkorb
- Bestellanfrage per vorbereiteter E-Mail
- Galerie ohne feste Bildanzahl
- Instagram/TikTok Links
- Eigener Browser-Editor unter `admin.html`
- Produkte, Preise, alte Preise, Kategorien, Bilder, Galerie und Social-Links editierbar

## Start
`index.html` im Browser öffnen.

## Editor
`admin.html` öffnen.

## Wichtig
Der Editor nutzt aktuell localStorage. Das bedeutet: Änderungen werden auf dem jeweiligen Browser/Gerät gespeichert. Für einen echten Live-Shop mit mehreren Geräten braucht die nächste Version ein Backend/CMS, Cloud-Speicher und später Zahlungs-/Versand-Integration.

## Nächster sinnvoller Schritt
Backend/CMS mit Login, Cloud-Bildverwaltung, echten Bestellungen, Stripe/PayPal, Versandregeln und E-Mail-Bestätigungen anschließen.

## Version 8 Änderungen
- Bilder und Hero-Bereich deutlich kompakter skaliert.
- Kategorien werden mit der Sprache gewechselt.
- Produktdetails, Maßanfertigung, Warenkorb-Leertext und Größenbezeichnung wechseln mit der Sprache.
- Pashto/Dari bleiben vollständig RTL.
- Sprachwahl wird beim Laden korrekt wiederhergestellt.

## Version 9 Änderungen
- Logo fest und zuverlässig über `assets/logo.gif` eingebunden; Logo kann im Editor ersetzt werden.
- Warenkorb → „Bestellanfrage senden“ öffnet WhatsApp mit allen Artikeln und Gesamtpreis bereits ausgefüllt.
- WhatsApp-Nummer ist im Editor änderbar.
- Produktbilder können im Editor per Datei-Upload ersetzt werden.
- Galerie-Bilder können per Datei-Upload ersetzt oder neue Bilder hinzugefügt werden.
- Alle bisherigen V8-Designs und Übersetzungen bleiben erhalten.

Hinweis: WhatsApp öffnet den Chat mit einer **vorbereiteten Nachricht**. Aus Sicherheits- und Browsergründen muss der Nutzer den WhatsApp-Senden-Button noch selbst drücken; eine Nachricht kann eine Website nicht heimlich automatisch absenden.

## Version 10 Änderungen
- Das echte AT Evening Elegance Logo ist jetzt auch groß und sichtbar rechts im Hero-Bereich der Startseite.
- Das Logo bleibt rund und dreht sich dezent um 360°.
- Wird das Logo im Editor geändert, wird auch das große Hero-Logo automatisch aktualisiert.

## Version 11 Änderungen
- Das Logo wird jetzt im Hero-Bereich wirklich kreisförmig zugeschnitten, auch wenn die Original-GIF-Datei einen quadratischen Hintergrund hat.
- Im Editor können die voreingestellten Produkte jetzt sicher gelöscht werden.
- Produktbilder können per Datei-Upload ersetzt werden.
- Produktbild-URL kann direkt geändert werden.
- Es gibt pro Produkt eine sichtbare Schaltfläche „Ändern speichern“.
- Galerie-Bilder können ebenfalls ersetzt oder gelöscht werden.
- Änderungen an Produkten und Bildern werden direkt im Browser gespeichert.
